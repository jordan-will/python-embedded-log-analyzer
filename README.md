# Embedded System Log Analyzer

A Python application for reading, parsing, validating, analyzing, and reporting embedded system log files.

## Project Objective

Develop a practical log analysis tool capable of processing log records, identifying malformed entries, generating statistics, filtering records, and exporting consolidated reports in JSON format.

## Features

- Read log files
- Parse log records
- Validate timestamps and fields
- Identify malformed records
- Analyze log entries
- Generate statistics by severity and component
- Filter records
- Generate consolidated reports
- Export reports to JSON

## Technologies

- Python 3
- Git
- JSON
- Python standard library
